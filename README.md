# NextTick

一个面向 Android 的轻量倒计时与任务切换提醒工具。核心目标很简单：**尽量让每一段时间都处于一个明确的倒计时里，减少无意识刷手机和任务拖延。**

## 主要功能

- 两步开始：先点标签，再点预设时长。
- 预设时长：5 / 10 / 15 / 20 / 25 / 30 / 40 分钟。
- 默认标签：学习、工作、日常、娱乐；支持新增、改名、换色和删除。
- 到点提醒：倒计时结束后进入提醒状态，默认每 10 秒轻提醒一次，直到打开应用或手动关闭。
- 空档提醒：关闭到点提醒后，如果没有开启下一段倒计时，每 1 分钟提醒一次。
- 切换积分：上一段结束后切换到不同标签，按每 10 分钟 1 分奖励；继续同一标签则扣除相同分数。
- 今日统计：环形图展示各标签时间占比，并用时间轴展示每段记录与积分。
- 设置：浅色/深色/跟随系统、中文/英文、震动开关、GitHub Release 更新检查。
- 重启恢复：设备重启或应用更新后会恢复计时状态并重新安排提醒。

## 构建

仓库自带 GitHub Actions。推送到 `main` 后会自动执行：

```bash
gradle assembleDebug
```

构建完成后，在 Actions 的 `NextTick-apk` artifact 中下载 APK。

打 `v*` 标签（例如 `v1.0.0`）后，工作流还会把 APK 附加到对应 GitHub Release，应用内“检查更新”读取的也是本仓库最新 Release。

## Android 说明

- `minSdk 26`
- `targetSdk 34`
- Kotlin + AndroidX + Material 3
- 本地数据使用 SharedPreferences + JSON，不上传个人记录。
- 计时依赖前台服务，并使用精确闹钟作为到点兜底。
- Android 13+ 需要允许通知，否则到点/空档通知无法显示。
- 某些厂商的强力省电策略可能额外限制后台运行；如遇到提醒不稳定，可在系统电池设置中允许 NextTick 后台运行。

## 积分规则

当前基础规则统一为：

- 切换到不同标签：`+ 实际时长 / 10`
- 继续同一标签：`- 实际时长 / 10`

例如：

- 学习 30 分钟后切换：`+3.0`
- 娱乐 10 分钟后切换到学习：`+1.0`
- 娱乐 15 分钟后切换：`+1.5`

提前结束会按实际记录时长计算。
