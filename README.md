# NextTick

一个面向 Android 的轻量倒计时与任务切换提醒工具。核心目标很简单：**尽量让每一段时间都处于一个明确的倒计时里，减少无意识刷手机和任务拖延。**

## 主要功能

- 两步开始：先点标签，再点预设时长。
- 预设时长可自行新增、删除。
- 默认标签：学习、工作、日常、娱乐；支持新增、改名、换色和删除。
- 到点提醒：默认每 10 秒提醒一次，可自行修改。
- 空档提醒：默认每 60 秒提醒一次，可自行修改。
- 提醒总开关：晚上等不需要督促时可整体关闭。
- 默认声音 + 震动；可单独关闭震动。
- 丰富的点击震动反馈。
- 切换积分：上一段结束后切换到不同标签，按每 10 分钟 1 分奖励；继续同一标签则扣除相同分数。
- 连续选择同一标签时会在扣分前弹出确认。
- 今日统计：环形图展示各标签时间占比，并用时间轴展示每段记录与积分。
- 浅色/深色/跟随系统、中文/英文、GitHub Release 更新检查。
- 重启恢复计时状态。

## 构建

仓库自带 GitHub Actions。推送到 `main` 后自动执行：

```bash
gradle assembleDebug
```

构建完成后，在 Actions 的 `NextTick-apk` artifact 中下载 APK。

## 固定公开签名

从 **v1.2.0** 起，仓库内直接保存固定签名文件：

`signing/nextick-public.jks`

Debug 和 Release 都使用同一签名，因此 GitHub Actions 后续构建的 APK 可以直接覆盖安装。签名和密码均公开，仅用于个人项目的更新兼容，不用于证明 APK 发布者身份。

注意：v1.1.0 及更早测试 APK 使用的是临时 CI Debug 签名，因此迁移到 v1.2.0 时需要最后卸载一次旧版。安装 v1.2.0 后，后续版本无需再卸载。

## Android 说明

- `minSdk 26`
- `targetSdk 34`
- Kotlin + AndroidX + Material 3
- 本地数据使用 SharedPreferences + JSON，不上传个人记录。
- Android 13+ 需要允许通知。
- 某些厂商的强力省电策略可能额外限制后台运行。

## 积分规则

- 切换到不同标签：`+ 实际时长 / 10`
- 继续同一标签：`- 实际时长 / 10`

例如：

- 学习 30 分钟后切换：`+3.0`
- 娱乐 10 分钟后切换到学习：`+1.0`
- 娱乐 15 分钟后切换：`+1.5`

提前结束按实际记录时长计算。

- 新增提醒总开关。
- 首页删除积分规则说明、空档教程文字和底部“两步开始”提示。
- 增强首页、统计页、设置页、标签管理、时长管理等操作的震动反馈。
- 加入固定公开 APK 签名，后续版本可直接覆盖安装。

## v1.1.0

- 状态栏/导航栏颜色与应用明暗主题统一。
- 到点提醒和空档提醒默认使用声音，并可通过设置决定是否同时震动。
- 到点重复提醒间隔可自定义。
- 无倒计时提醒间隔可自定义。
- 首页预设时长改为紧凑数字按钮，并支持新增/删除常用时长。
- 连续选择同一标签时，在扣分前弹出确认提示。


## v1.3.0

- 首页标签支持自动换行，标签多时直接显示为两行、三行，不再横向滚动。
- 时间轴压缩为一条记录一行。
- 首页从“今日积分”改为“累计积分”，每日积分账本仍按日期保留。
- 设置页新增“数据管理 → 导出全部数据”。
- JSON 备份包含全部标签、预设时长、历史时间轴、每日积分、累计积分、提醒设置、主题/语言设置和当前计时状态。


## v1.4.0

- 运行中的倒计时禁止被第二次点击时长重置，UI 与计时核心均做了双重保护。
- 统计页不再使用嵌套 RecyclerView，今日全部时间轴记录会完整展开显示。
- 时间轴每条记录可点击删除；删除后对应时长和积分会一起从统计中回滚。
- 饼图移除独立图例，标签名称与时长直接通过引导线标注到对应扇区周围，更紧凑。


## v1.5.0

- 首页标签固定四列排列，标签较多时自动变为 4+N 的多行网格。
- 倒计时操作按钮并入计时数字同一行，减少首页纵向占用。
- 饼图标签引导线改为单段直线，不再使用折线；中心总时长自动缩放以保持在内圈范围内。
- 统计页新增前一天/后一天切换，并可点击日期快速回到今天，历史日期可长期回看。
- 修复检查更新请求，补充 GitHub API User-Agent；检查失败时可直接从浏览器打开 Releases 下载页。
- GitHub Actions 在 main 构建成功后自动创建/更新对应版本的 GitHub Release，应用内检查更新有真实 Release 可读取。
